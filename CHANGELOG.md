# Changelog

## v1.0.0 — 2026-10-10

Первый публичный релиз.

### Добавлено
- Добавление видео по ссылке (YouTube): метаданные, обложка, длительность
- Скачивание в фоне (yt-dlp + ffmpeg на устройстве): прогресс, скорость, отмена,
  восстановление задач после перезапуска
- Выбор качества видео
- Аудиодорожки: оригинал / русская озвучка / обе дорожки (mkv с двумя треками,
  подписанными языком)
- Библиотека скачанных видео: карточки с обложкой, длительностью, датой; экран
  деталей; удаление
- Оффлайн-плеер (Media3/ExoPlayer): запоминание позиции, полноэкранный режим,
  переключение аудиодорожек, пауза при уходе в фон
- Комментарии к видео с ответами (раскрытие по тапу «N ответов»)
